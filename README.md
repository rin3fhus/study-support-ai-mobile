# 学習サポートAI（スマホ版）

パソコン版（AIあり）と対になる、AIなしのスマホ版です。
パソコンを開いていなくても、スマホのブラウザで勉強できます。
記録は Firebase に保存され、パソコン版と共通です（どちらで勉強しても、もう一方に反映されます）。

## 入っているもの

- `study-support-ai-mobile.html`：アプリ本体（このファイルを開いて使う）
- `data/`：シード問題820問・用語カード492語・テーマ82件・予習ガイド82件・混同ペア79組のデータ
- `yoten/`：要点まとめ画像82枚
- `illustrations/`：予習ガイドで使うイラスト3枚（アプリ独自のもの）

教科書の本文・教科書由来のデータは入っていません（パソコン版だけに置く決まりのため）。
予習ガイドは、パソコン版のアプリ独自の解説（テーマごとの導入文・キーワード・図解）です。

## 使い方

1. パソコン版で、アカウントを登録しておく
   （パソコン版の「その他 → 設定 → 📱 スマホ版とつなぐ（アカウント）」で「新規登録してつなぐ」）
2. スマホ版を開き、同じメールアドレスとパスワードでログインする
3. ホームの「今日やる学習」から勉強を始める

## できること

- 今日やる学習リスト（今日の復習・おすすめテーマ・今日の間違い・期限が近いレポート）
- 予習ガイド（テーマごとの導入文・キーワード・図解・イラスト・要点画像・関連テーマ。
  おすすめテーマとテーマ一覧の「予習」ボタンから開けて、そのまま問題を始められる）
- 問題を解く（シード問題、1テーマ10問まで。記録はその場で保存される）
- 今日の復習（パソコン版と同じ間隔の規則で進む）
- テンポ復習（1問あたり30・20・10秒。時間切れは不正解として、パソコン版と同じ規則で記録される）
- 形式ドリル（テーマと形式を選んで5問）／科目内テーマミックス（科目内のテーマを混ぜて10問）
- 模擬試験（科目指定または全科目ミックス、問題数と制限時間を選べる、苦手テーマ優先あり。
  結果は科目別スコアつきで表示され、記録はパソコン版と共通）
- 学習プランの表示（試験までの日数・週ごとの計画の目安・レポート一覧と期限・進み具合。閲覧のみ）
- 間違いノートと、今日の間違い直し
- 用語カードと言葉クイズ（言葉クイズの結果は記録に残らない）
- 混同ペア（79組の一覧と、説明から用語を当てるクイズ。クイズの結果は記録に残らない）
- お気に入り（テーマ・問題・用語）と「あとで解く」（問題画面から登録。ノート画面で確認できる）
- ノート（メモ・疑問メモなど。追加・編集・削除ができ、パソコン版と共通）
- 要点まとめ画像の閲覧
- 記録・統計の閲覧（解いた数・正解率・科目ごとの進み具合・学習時間）
- 表示設定（文字の大きさ5段階・フリガナのオン/オフ・フリガナの大きさ。この端末に保存される）

通信できないときは、記録がこの端末に控えられ、つながったときに自動で送られます。
（削除した記録は、パソコン版の同期の仕組み上、パソコン側のデータには残ります）

## GitHub Pages で公開する手順（後で本人が実行する分）

1. GitHub で新しいリポジトリを作る（名前は例えば `study-support-ai-mobile`）
   ※ すでに公開済みの場合は、同じリポジトリに新しいファイルで上書きアップロードするだけでよい
2. このフォルダの中身を、すべてアップロードする
   - `study-support-ai-mobile.html`
   - `data` フォルダ（中身ごと）
   - `yoten` フォルダ（中身ごと）
   - `illustrations` フォルダ（中身ごと）
3. アップロードするとき、`study-support-ai-mobile.html` の名前を `index.html` に変えておくと、
   Pages のアドレスを開いただけでアプリが表示される
   （名前を変えない場合は、アドレスの最後に `/study-support-ai-mobile.html` を付けて開く）
4. リポジトリの Settings → Pages で、公開元（branch）を `main`（ルート）に設定して保存する
5. 数分待つと、`https://＜ユーザー名＞.github.io/study-support-ai-mobile/` で開けるようになる
6. スマホのブラウザで開いて、ホーム画面に追加しておくと便利

※ このアプリは本人のアカウントでログインしないと記録が見られない作りですが、
  ページ自体は公開アドレスになります。シード問題と要点画像だけが置かれる形で、
  学習記録や教科書の本文は含まれません。
